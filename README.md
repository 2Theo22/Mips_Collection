# Mips_Collection
A collection of programs I had to write in mips for university 

## LeapYear.asm
This program takes a year (via user input) and then checks if the given year is a leap year

## german_umlaut_converter.asm
This program will take a string via user input and convert as followed
ä -> ae
ü -> ue
ö -> oe
ß -> ss

And then return the converted string

## Euclidean_algorithm.asm
Will take two integers as input and finds the greatest common divisor.

## Hypotenuse.asm 
Will take a and b via user input and calculate a² + b² = c².
